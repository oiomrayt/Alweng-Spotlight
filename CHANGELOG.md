## [1.0.0] - 2026-08-15

### Added

- Physical Apple Spotlight-key remapping through macOS `hidutil`.
- Configurable English input source in the menu bar.
- macOS 26 focus workaround for reliable input-source switching.
- Accessibility onboarding, test action, and clean mapping restoration.
- Native arm64/x86_64 build and GitHub release workflow.
